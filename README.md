📌 Project Overview
This project focuses on a blockchain-based patient-centric Electronic Health Record (EHR) management system. It aims to provide secure, privacy-preserving, and efficient management of electronic health records using blockchain technology.

🔐 Key Technologies
Blockchain
Smart Contracts
IPFS
Encryption
Access Control
Transaction Batching
🎯 Project Objective
To design and evaluate an efficient transaction batching mechanism that improves transaction processing performance and scalability while maintaining security, privacy, access control, and data integrity.
